> 时长预估：约 10 分 30 秒
> 面向观众：学生 + 职场 1–5 年
> 一句话价值：**同样的知识，为什么有人能用、有人用不出？因为缺了这三件事。**

## 二、分镜详表

### 0. ColdOpen（0:00–0:25）
- 黑幕，三个疑问一句一闪：
  1. "先有鸡，还是先有蛋？"
  2. "没有砝码，怎么用天平三次找出 12 个球里质量异常那一个？"
  3. "作文题目突然给你几张图，你怎么破题？"
- 最后一句汇入中央：**"同样的知识，为什么有人能用，有人用不出？"**

### 1. TitleCard（0:25–1:15）
- 中央浮现《如何思考》大字，副标题"方法论三板斧"
- 下方三块小卡：**根本 · 角度 · 结构化**，逐张翻开
- 上方横排 logo 贴片（5Why / 5W2H / SWOT / PEST / KANO / MAT / PDCA）浮出后淡化为背景

### 2. PillarOne_Root（1:15–3:20）
- 黄色高亮条"**第一板斧 · 根本**"入场
- 三行要点：根本定义 / 根本目的 / 根本原因
- 股票案例动画：
  - 左：股价曲线上行
  - 右：指向"信心"节点，再由信心拆出三条来源——财报 / 舆论 / 客户满意度
  - 关键反转："**财报好 ≠ 股价涨**；只有让人产生信心才会涨"
- app 案例文字帧：
  - 设计师把页面做得很开心 → **加氛围 / 加点击，到底是为了啥？**
  - 引回到"目的"两个字

### 3. PillarTwo_Angle（3:20–5:50）
- 三个角度围一圈，中央是"问题"
  - 身份角度：用户 / 供应商 / 携程
  - 时代角度：弱信息时代 ← 强信息时代
  - 抽象层次：具体事物 → 规律 → 规律的规律
- 时代动画：箭头从"告知"翻转为"反向迎合"
- 抽象动画：数列 → 函数 → 导数，变量越抽越少

### 4. PillarThree_Structure（5:50–8:20）
- 中央"问题"，向下按「维度 A / 维度 B / 维度 C」三叉切开
- MECE 示意：三块不重叠、全覆盖
- 案例：用"地点 / 用车时间 / 人不符"三维拆"无结果原因"
- 文字总结：**在根本 + 角度之上，才谈得上好的拆解**

### 5. Synthesis（8:20–9:30）
- 回到开场三题，每题用一句话给出三板斧解法：
  - 先有鸡：**根本定义**——你问的"鸡"是什么？基因突变体 vs 生下它的蛋
  - 天平：**结构化拆解**——三次称重 3^3 = 27 > 12，按三分维度切
  - 作文：**角度**——身份角度 + 抽象层次选题

### 6. Outro（9:30–10:30）
- 三板斧小卡合体，旋转为频道 Logo
- 下集预告："下集《自然启蒙》：什么在变，什么不变？"
- 结尾静帧 2 秒

## 三、动画实现要点

- 全程深色背景 (`C_BG`)，字使用 `CJK_FONT`
- 三板斧各用独立颜色：根本=黄，角度=蓝，结构化=绿
- 关键句用 `highlight_box` 加黄色底纹
- 转场统一使用 `chapter_card(..)`
- 箭头建议 `Arrow(stroke_width=4)` 显瘦长
