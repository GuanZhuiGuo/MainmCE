## 二、分镜详表

### Beat 0 · ColdOpen
- **画面**：纯黑底。文本一条一条从底部升起，白色。
- **节奏**：每题停 0.8 秒；三题后合成一句问"差什么"。
- **技术**：`fade_in_up` + `FadeOut(shift=UP)`；最后一句黄色 `cn_bold`。

### Beat 1 · TitleCard
- **画面**：中央《如何思考》+ 副标题"方法论操作系统"。
- 上方一行 chips：5Why / 5W2H / SWOT / PEST / KANO / MAT / PDCA（淡出为背景）。
- 下方三卡：① 根本（黄色框）② 角度（蓝色框）③ 结构化（绿色框）。
- 波普尔引言条用小字灰色置于底部，5秒后淡出。

### Beat 2 · PillarOne_Root
- **子画面 A**（股票）：
  - 左侧：Axes 画一条股价曲线（真实感，含随机噪声）。
  - 右侧：节点图：信心 → 股价（粗黄箭头），财报 / 舆论 / 满意度 → 信心（蓝/紫/橙细箭头）。
  - 反转高亮："财报好 ≠ 股价涨"闪红 + Flash。
  - 新增：在股价曲线上叠"预期线"（虚线），让观众**看到**"预期差"。
- **子画面 B**（App）：
  - 文字链：氛围 → 停留 → 浏览深度 → 成交，每步之间用 Arrow 连。
  - 最后"成交"放大高亮 + 费曼引言置底。
- **子画面 C**（动作帧）：
  - 便签卡："根本定义？根本目的？根本原因？"三行，加手写字体效果。

### Beat 3 · PillarTwo_Angle
- 中央"问题"圆圈，向三方发射箭头：
  - 左上：身份角度（用户 / 供应商 / 平台 三头像 icon）。
  - 右上：时代角度（两个时间箭头反转动画）。
  - 下方：抽象层次（四级阶梯：现象 → 规律 → 元规律 → 数学）。
- 阶梯动画：每升一级，卡片变小 + 颜色变深，文字变"公式感"。
- 新增 beat：**米勒定律** 视觉——工作记忆 4±1 条目的脑图。

### Beat 4 · PillarThree_Structure
- 顶部"问题"矩形 → 向下分叉三支：维度 A / B / C。
- MECE 示意：三个矩形拼合刚好覆盖上方问题的宽度（视觉无缝）。
- 案例"打车"切入后，用三色柱对比信息量。
- 总结句黄色高亮+Indicate。
- 新增元素：底部浮出"信息论补充"——小字灰色"3³=27 > 24"。

### Beat 5 · Synthesis
- 左中右三列卡片，每列对应一道题：
  - 题面(白) → 用了哪把刀(彩) → 一句话答案(灰)。
- 每张卡片自带小编号和颜色条，依次 fade_in_up。

### Beat 6 · Outro
- 三板斧合成一个循环箭头 logo。
- 下集预告"自然启蒙 · 变与不变"。
- 右下 footer 保持。
