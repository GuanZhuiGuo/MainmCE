## 二、分镜要点

### Beat 1 · NumbersZoo
- NumberLine 从 0 开始向右伸展（自然数黄色点）。
- 向左伸展（负数红色点）。
- 0 出现（蓝色闪）。
- 分数用更小的绿色点标注在线中间。
- √2 和 π 用紫色大点标注 + MathTex 上方。
- 底部文字："每次扩张 = 旧语言说不清新事实。"

### Beat 2 · UnitsMatter
- 中央"50"大字（黄色 120pt）。
- 下方翻出 4 张 RoundedRectangle："50米 / 50秒 / 50元 / 50度"不同色。
- 然后用"×"把 50 米 和 50 秒连一条线 → 冒出 "50m × 50s = ??"（量纲荒谬）。
- 最后出现"量纲分析"关键句 + 日常应用提示（灰色小字）。

### Beat 3 · Equations
- 左侧三条 MathTex 公式（路程/力/利润）。
- 右侧 Axes：ValueTracker 控制 k 和 b → 直线随参数实时滚动。
- 底部新增：弹簧/欧姆/小角摆三个小图标暗示"线性无处不在"。

### Beat 4 · FunctionsAndDerivatives
- **曲线**：y = 0.4x² ；蓝色。
- **运动点**：黄色 Dot 沿曲线移动（ValueTracker 0→4）。
- **切线**：TangentLine 跟着动点旋转；同步显示斜率数字。
- **积分**（新增）：当 x 从左向右走完，曲线下方 fill（浅蓝半透明），
  显示 ∫f(x)dx 的面积数字增大。
- 结尾高亮句："导数 = 变化的速率。积分 = 变化的累积。"

### Beat 5 · Closing
- 四行对齐卡片（面积 / 气温 / 股票 / 心跳 → 数学描述）。
- Wigner 引言置底灰色。
